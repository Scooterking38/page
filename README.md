# Project Title: Calculator Application

## One-line Tagline:
A simple calculator application built with Python, featuring both GUI and command-line interfaces.

## Architecture Overview:
The repository contains a basic calculator application that supports both graphical user interface (GUI) and command-line operations. The application is structured into several components:

- **calculator.py**: This file handles the logic for the calculator's operations using PySide6 for the GUI.
- **calculator.ui**: A UI file generated by Qt Designer, which defines the layout of the calculator's graphical interface.
- **unknown.py** and **unknown_support.py**: These files contain a secondary implementation of a calculator using Tkinter. This part of the application is less integrated with the main project structure.

The `calculator.py` script uses PySide6 to load the UI file and handle user interactions, while `unknown.py` and `unknown_support.py` provide an alternative implementation using Tkinter. The presence of both GUI frameworks suggests that this repository might be a work in progress or a comparison between different GUI libraries.

## Tech Stack:
- **Programming Language**: Python
- **GUI Frameworks**:
  - PySide6 (for the main calculator application)
  - Tkinter (for the alternative implementation)
- **Libraries**:
  - `sys` for system-specific parameters and functions.
  - `PySide6.QtWidgets`, `PySide6.QtUiTools`, `PySide6.QtCore` for GUI components and event handling in PySide6.
  - `tkinter`, `tkinter.ttk` for GUI components in Tkinter.

## Getting Started / Setup Guide:

### Prerequisites:
- Python 3.x installed on your system.
- Install the required libraries using pip:
  ```bash
  pip install PySide6
  ```

### Steps to Run the Application:

1. **Clone the Repository:**
   ```bash
   git clone <repository-url>
   cd page
   ```

2. **Run the Main Calculator Application (PySide6):**
   ```bash
   python calculator.py
   ```
   This will launch the calculator with a graphical interface.

3. **Run the Alternative Calculator Implementation (Tkinter):**
   - Open `unknown_support.py` and run it:
     ```bash
     python unknown_support.py
     ```
   This will launch an alternative calculator using Tkinter.

### Notes:
- The `calculator.ui` file is necessary for the PySide6 application to function correctly. Ensure that this file is in the same directory as `calculator.py`.
- The Tkinter implementation (`unknown.py` and `unknown_support.py`) is less integrated with the main project structure, so it may require additional configuration or adjustments.
